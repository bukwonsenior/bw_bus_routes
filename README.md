# 북원노인종합복지관 셔틀버스 노선도

복지관 셔틀버스 3개 코스(오전 1코스 / 오전 2코스 / 오후 코스)의 운행 노선을 카카오맵에 표시합니다.

## 게시 주소

| 용도 | 주소 |
|---|---|
| 홈페이지 게시용 (모바일·PC 반응형) | `https://fangram8779-prog.github.io/bw_bus_routes/` |
| 인쇄용 (A4 가로 3장) | `https://fangram8779-prog.github.io/bw_bus_routes/print.html` |

### 홈페이지 삽입 코드

```html
<iframe src="https://fangram8779-prog.github.io/bw_bus_routes/"
        style="width:100%;height:760px;border:1px solid #ddd;border-radius:8px"
        title="셔틀버스 운행 노선"></iframe>
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `route_data.js` | **노선 데이터 (원본)** — 정류장 순서·시간·좌표를 여기서만 수정 |
| `index.html` | 홈페이지 게시용 지도 |
| `print.html` | 인쇄용 노선도 (A4 가로, 큰 글씨) |
| `stops.csv` | 정류장 마스터 42개소 |
| `routes_수정본.csv` | 순번 재부여 결과 (엑셀 대조용) |
| `적용안내.md` | 상세 사용 설명서 |
| `build_data.py` | 데이터 재생성 스크립트 |
| `verify.py` | 시간 역행·거리 이상 자동 검증 |
| `preview.py` | 좌표 검증 미리보기 이미지 생성 |

## 노선 현황

| 코스 | 운행 시간 | 정차 | 주행거리 |
|---|---|---|---|
| 오전 1코스 (태장·소초 방면) | 07:50 ~ 09:00 | 27개소 | 약 20.7 km |
| 오전 2코스 (호저 방면) | 09:05 ~ 09:50 | 16개소 | 약 15.4 km |
| 오후 코스 (전체 방면, 퇴원) | 13:30 ~ 15:00 | 35개소 | 약 29.2 km |

## 노선 수정 방법

`route_data.js` 의 `routes` 부분에서 정류장 순서·시간만 수정하면 지도와 시간표가 함께 갱신됩니다.

```bash
python3 verify.py   # 수정 후 시간 역행·거리 이상 점검
```

자세한 내용은 [적용안내.md](적용안내.md) 참고.

## 좌표 확인 필요 정류장

아래 7개소는 장소 검색으로 정확한 좌표를 찾지 못해 노선 순서로 추정한 값입니다.
지도에서 위치가 어긋나 보이면 카카오맵에서 좌표를 확인해 `route_data.js` 의 `lat`/`lng` 를 수정해 주세요.

- 가현코어텍, 가현동, 장양리차고지, 양촌, KBS송신소, 현대자동차
- 상록아파트 (동명 2개소 존재 — 현충로 234 상록프라자로 판단)
