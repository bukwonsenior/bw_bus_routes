# 북원노인종합복지관 셔틀버스 노선도

복지관 셔틀버스 3개 코스(오전 1코스 / 오전 2코스 / 오후 코스)의 운행 노선을 카카오맵에 표시합니다.

## 게시 주소

| 용도 | 주소 |
|---|---|
| 홈페이지 게시용 (모바일·PC 반응형) | `https://fangram8779-prog.github.io/bw_bus_routes/` |
| 인쇄용 (A4 가로 3장) | `https://fangram8779-prog.github.io/bw_bus_routes/print.html` |

### 홈페이지 삽입 코드

```html
<iframe src="https://fangram8779-prog.github.io/bw_bus_routes/"
        style="width:100%;height:760px;border:1px solid #ddd;border-radius:8px"
        title="셔틀버스 운행 노선"></iframe>
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `route_data.js` | **노선 데이터 (원본)** — 정류장 순서·시간·좌표를 여기서만 수정 |
| `index.html` | 홈페이지 게시용 지도 |
| `print.html` | 인쇄용 노선도 (A4 가로, 큰 글씨) |
| `stops.csv` | 정류장 마스터 42개소 |
| `routes_수정본.csv` | 순번 재부여 결과 (엑셀 대조용) |
| `적용안내.md` | 상세 사용 설명서 |
| `build_data.py` | 데이터 재생성 스크립트 |
| `verify.py` | 시간 역행·거리 이상 자동 검증 |
| `preview.py` | 좌표 검증 미리보기 이미지 생성 |

## 노선 현황

| 코스 | 운행 시간 | 정차 | 주행거리 |
|---|---|---|---|
| 오전 1코스 (태장·소초 방면) | 07:50 ~ 09:00 | 27개소 | 약 18.8 km |
| 오전 2코스 (호저 방면) | 09:05 ~ 09:50 | 16개소 | 약 13.8 km |
| 오후 코스 (전체 방면, 퇴원) | 13:30 ~ 15:00 | 35개소 | 약 26.0 km |

## 노선 수정 방법

`build_data.py` 의 `STOPS` / `R_AM1` / `R_AM2` / `R_PM` 을 수정한 뒤 실행하면
지도·시간표·CSV가 모두 재생성됩니다. **순번은 자동 부여**됩니다.

```bash
python3 build_data.py   # route_data.js 등 재생성
python3 verify.py       # 시간 역행·거리 이상 점검
```

자세한 내용은 [적용안내.md](적용안내.md) 참고.

## 좌표 출처

전 정류장 좌표는 **국토교통부 전국 버스정류장 위치정보(2025-10-31)** 의 원주시 실측 좌표를
정류장번호(모바일단축번호)로 매칭해 적용했습니다. 39개소 전부 매칭 완료.

- 복지관, 코아텍, 우산동 삼호아파트 정문 3개소는 버스정류장이 아니라 별도 제공 좌표 사용
- 원주시 전체 정류장 3,173개소 좌표는 `원주시_버스정류장_좌표.csv` 에 보관되어 있어
  새 정류장 추가 시 바로 조회할 수 있습니다
